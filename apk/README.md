# Herald Resume Android Application

This directory contains pre-built Android application packages (`.apk`) for the Herald Felisilda Resume app.

## Available APKs

- **`app-release.apk`**: Production release build, signed and optimized for installation on Android devices.
- **`app-debug.apk`**: Debug build for testing and inspection.

## Installation

### Via ADB
```bash
adb install -r app-release.apk
```

### Direct Install on Android
1. Download `app-release.apk` to your Android device.
2. Open the file from your notifications or File Manager.
3. If prompted, allow "Install Unknown Apps" for your browser or file manager.
4. Follow the on-screen prompt to finish installation.
