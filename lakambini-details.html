Miss Lakambini 2026

Official coronation campaign site for Quenny Avah M. Felisilda of Hinlayagan Ilaya Elementary School — public support pages with GCash confirmation, a verified donors wall, and an admin panel to validate donations.

About This Application

Dual-surface campaign platform: a public site for candidate storytelling and GCash support, plus a lightweight admin area to review, activate, and manage donation records. Proceeds support the school kitchen & dining tables project. Supporters submit a confirmation form after paying; only activated donations appear on the public Wall of Gratitude.

  • Public: Home (countdown), About, Program, Support (QR + form), Donors registry
  • Donations: GCash ref validation, pending → active workflow, privacy-masked names
  • Admin: Login, donor CRUD/validation, profile & password change
  • Hardening: CSRF, honeypot, rate limits, field checks; timezone Asia/Manila

Stack, Tools & Plugins

  • Public + Admin: PHP + Tailwind CDN + Font Awesome
  • Storage: JSON files under data/ (donations, admin users)
  • Email: SMTP / PHP mail for donation notifications
  • UX: jQuery + SweetAlert + DataTables (admin)
  • Mobile: PWA (service worker) + Capacitor 8 WebView APK
  • SEO: Open Graph, sitemap, robots, structured metadata
  • Ops: Form anti-abuse layers, session-based admin auth
