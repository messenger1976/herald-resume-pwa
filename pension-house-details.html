BODARE Pension House App

A full hospitality booking platform for BODARE Pension House in Tagbilaran City — guest-facing PWA/mobile booking plus a CodeIgniter 3 admin panel for rooms, bookings, billing, inquiries, roles, and operations.

Open Live Site Frontend Backend Back to Portfolio
PHP + CodeIgniter 3 MySQL PayMongo QR Ph / Card PWA + Capacitor 7 Firebase FCM

About This Application

Dual-surface platform: a public guest site for discovery and booking, and a BODARE Admin panel for operations. Guests book rooms, check out, and pay online (QR Ph / Card via PayMongo). Staff manage bookings, calendar, rooms, guests, invoices, payments, inquiries, roles/ACL, activity logs, SMTP, and database backups.

  • Public: Home, Rooms, Amenities, Gallery, Contact, Location, Cart, Checkout, QR Pay
  • Guest account: Login, Bookings, Invoices, Profile, Security, Inquiry
  • Admin: Dashboard, Bookings, Calendar, Rooms, Guests, Billing, Reports, ACL
  • Timezone policy: Asia/Manila for all transaction timestamps

Stack, Tools & Plugins

  • Public site: PHP + JS (Tailwind CDN)
  • Admin: CodeIgniter 3 + Bootstrap forms
  • Database: MySQL
  • Payments: PayMongo (QRPH + Card Hosted Checkout)
  • Email: SMTP + IMAP inquiry sync
  • Mobile: PWA + Capacitor 7 WebView APK
  • Push: Firebase FCM (native APK)
  • Ops: Activity logs, ACL roles/groups, DB backup vault
