Bohol Island Tours

Tourism and booking platform for Tagbilaran-based Bohol Island Tours — multi-day packages, destinations guide, vehicle rentals, inquiry/contact flows, plus a CodeIgniter 3 admin panel for bookings, customers, inquiries, reports, and ACL.

About This Application

Dual-surface travel platform: a public marketing/booking site for packages and rentals, and an admin panel for operations. Visitors browse destinations, compare 2D1N–5D4N itineraries, request quotations, and reach the team via contact form or Facebook Messenger. Staff manage bookings, customers, inquiries, email settings, reports, and role-based access.

  • Public: Home, Tour Packages (2D1N–5D4N), Destinations, About Bohol, Car/Van Rental, Contact
  • Guest flows: quote/inquiry, newsletter, Messenger chat, optional login & customer dashboard
  • Admin: Dashboard, Bookings, Customers, Inquiries, Reports, Users / Groups / Roles
  • SEO: JSON-LD, Open Graph, sitemap, robots; PWA manifest + service worker

Stack, Tools & Plugins

  • Public site: PHP pages + custom CSS/JS theme
  • Admin: CodeIgniter 3 MVC under admin/
  • Database: MySQL (bookings, customers, ACL)
  • APIs: Auth, Booking, Inquiry, User REST endpoints
  • Client: api-config.js / booking-api.js
  • Comms: SMTP settings + Facebook Messenger float
  • Ops: Granular RBAC, reports, module generator, PWA
